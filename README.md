# 🎬 Reviews Website API 💬
API Rest developed on NestJS for a reviews website

## ⚙️Setup
Set the following enviroment variables:
- DB_USERNAME (Database Username)
- DB_PASSWORD (Database Password)
- DB_DATABASE (Database Name)
- AUTH_SECRET (JWT Secret Key)
- PORT (API Port)
- ORIGIN (CORS Origin Sites)

Run the following commands:

    $ npm i
    $ npm run start

There are some SQL scripts in the repository to insert dummy movies for testing purposes

## 📝 Features
Functional features:
+ Review movies
+ Comment reviews
+ Create and join groups
+ Create group meetings

Technical features:
+ Auth system
+ JWT integration
+ Roles system
